# Rapid MLX for Chrome

Short description: Connect your model to browser tasks with explicit tab sharing, action approvals, and Stop.

Long description:
Rapid helps you research, compare products and travel options, find reservations,
and draft replies from pages you choose to share. Connect Rapid on this Mac or
configure your own compatible model endpoint. Choose a loaded model, test tool
calling, and set reasoning effort in Settings.

Start with three steps: connect a model, share a tab, and try an example task.
Rapid shows its tool steps and asks for approval before visiting a new site or
performing a consequential action. Approvals apply once. Stop cancels execution
and releases browser control. Human verification and sensitive input stay with you.

Model quality and website behavior affect results. Always check the final cart
price and review consequential actions. A running model server with tool calling
is required; models and hosting are not included. English and Simplified Chinese
interfaces follow the browser language. No telemetry or advertising.
