# Decision console — feel the three lanes directly

Type any request; Marvin answers route / gate / guard in one forward pass
each (~1.1 s, zero generated tokens). Routing shows the policy-derived
ground truth next to Marvin's pick.

```bash
python marvin_console.py --demo   # six canned scenes
python marvin_console.py          # interactive REPL (--ram 12 to flip constraints)
```
