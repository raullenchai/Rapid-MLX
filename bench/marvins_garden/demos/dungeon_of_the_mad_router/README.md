# The Dungeon of the Mad Router — text dungeon crawled by Marvin

Five chambers. The Warden (injection guard) judges every typed deed —
reality-hacks get blocked, three strikes and you are exiled. The Oracle
(tool gate) decides whether a turn queries the world for a hint. The Circle
(model routing) summons each challenge's spirit; your lantern power is the
host-RAM constraint, so an under-powered summon hurts.

```bash
python dungeon_of_the_mad_router.py --auto   # scripted winning run
python dungeon_of_the_mad_router.py          # play it yourself
python make_playthrough_video.py <log> <out.mp4>   # turn a run into a video cast
```
