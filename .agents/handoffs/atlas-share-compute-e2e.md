## Live-access contract

- A temporary `qsppk-` provider key registers this Studio Mac under a unique worker name.
- A limited-credit `sk-` consumer inference key calls `nemotron-3.5-lightning`, and a `qsprk-` read-only ledger key reads the same provider account.
- QuickSilver provides read-only tracing from gateway request ID to node ID and accounting window. A successful response alone cannot establish which node served it when a model has multiple ready nodes.
- A separate low-limit `sk-` key exercises HTTP 429 without affecting normal account traffic.

Keep credentials out of Git, shell history, logs, and this handoff. Signed/notarized release validation remains Harbor-owned and requires release authorization.
