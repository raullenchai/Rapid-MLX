Rapid-MLX 0.15.4 adds an experimental, opt-in accelerated profile for
Qwen3.8-27B and an experimental Share Compute experience in Desktop. Share
Compute is enabled from Settings → Experimental. Both features keep their
operating limits visible and provide a clear route back to ordinary local
serving.

## Highlights

**Qualified Qwen3.8-27B acceleration.** `qwen3.8-27b-tensorfold` provides a
serial, text-only accelerated profile for Apple Silicon Macs with at least
48 GB of unified memory. It pins the target, drafter, MLX, and optional runtime
identities; startup fails closed if they do not match. Desktop exposes the
profile through the normal model picker, leaves acceleration off by default,
shows live engine-confirmed status, and directs tools, media, grammar, and
other unsupported work to the ordinary `qwen3.8-27b-4bit` profile.
([#3929](https://github.com/raullenchai/Rapid-MLX/pull/3929),
[#3930](https://github.com/raullenchai/Rapid-MLX/pull/3930),
[#3934](https://github.com/raullenchai/Rapid-MLX/pull/3934))

The accelerated profile advertises and enforces a one-request limit, rejecting
overlapping requests before reading their bodies. It does not make a fixed speed
or quality claim. Qualification samples from both the accelerated and ordinary
paths missed some fixture constraints, and their warm prefix-cache behavior
differs.

**Experimental Share Compute in Desktop.** After enabling Share Compute in
Settings → Experimental, new Share, Live Pool, and Credits views make it
possible to contribute an eligible local model, inspect connection and session
state, and review credited activity from the app. Read-only account keys are
stored in the macOS login Keychain, small positive credits remain visible, and
the setup guide covers the Desktop and command-line paths. Live acceptance
verified ordinary and streaming requests, multi-node routing, credited ledger
rows, clean shutdown, and the rebuilt Credits view.
([#3923](https://github.com/raullenchai/Rapid-MLX/pull/3923),
[#3927](https://github.com/raullenchai/Rapid-MLX/pull/3927))

**Opt-in dense batch acceleration for operators.** A separately licensed
row-invariant matrix-multiplication lane is available for qualified dense
layouts through `RAPID_MLX_LANE_MATMUL`; it remains off by default. On the
qualified setup, the lane uses a distinct numerical law and does not claim
stock token identity, a fixed performance improvement, or universal quality
neutrality, so it is intended for explicit operator evaluation.
([#3931](https://github.com/raullenchai/Rapid-MLX/pull/3931))

**Release-safe optional runtime setup.** Published wheel and source metadata
contain no direct Git dependency, which public package indexes reject. The
experimental Qwen runtime remains explicitly installable from its exact
qualified revision through the CLI guidance, and release gates now inspect both
distribution formats before publication.
([#3937](https://github.com/raullenchai/Rapid-MLX/pull/3937))
