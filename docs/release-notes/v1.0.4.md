Rapid-MLX 1.0.4 makes coding-agent launches work on the first try, adds MiniMax-H3-Image and FLUX 3 Klein with multi-reference edits, and lets you serve a local LoRA adapter without fusing it. Long-context cache hits also reach the first token sooner, and several API errors that returned 500 now succeed or return a clear 400.

**Download:** [Rapid-MLX Desktop for macOS](https://github.com/raullenchai/Rapid-MLX/releases/download/rapid-mac-v1.0.4/rapid-mlx-desktop.dmg) | CLI: `rapid-mlx upgrade` or `curl -fsSL https://rapidmlx.com/install.sh | bash`

## Coding Agents Work on First Launch

`rapid-mlx launch` and `rapid-mlx agents` were tested end to end on a clean Mac with Codex, Claude Code, Pi, OpenCode, Hermes, Goose, Qwen Code, Crush and Aider, covering setup, a real coding task and removal.

- Agent setup no longer fails when the server is not running yet or is still loading a model. The agent is configured first, and readiness waits are bounded with a clear message ([#5804](https://github.com/raullenchai/Rapid-MLX/pull/5804)).
- Claude Code launches with the model's real context window and without a billing notice. Removing the setup restores the settings you had before and keeps edits you made since ([#5811](https://github.com/raullenchai/Rapid-MLX/pull/5811), [#5840](https://github.com/raullenchai/Rapid-MLX/pull/5840)).
- Hermes no longer consumes your first message as the answer to its telemetry question, and `--remove` reliably cleans up ([#5813](https://github.com/raullenchai/Rapid-MLX/pull/5813), [#5815](https://github.com/raullenchai/Rapid-MLX/pull/5815)).
- Aider runs shell commands in your own shell, so commands such as `echo -n` behave as they do in your terminal. Its isolated profile also includes model metadata, which stops the unknown-model warning ([#5828](https://github.com/raullenchai/Rapid-MLX/pull/5828), [#5818](https://github.com/raullenchai/Rapid-MLX/pull/5818)).
- Qwen Code starts with a valid empty settings file in its isolated home ([#5812](https://github.com/raullenchai/Rapid-MLX/pull/5812)).
- The built-in agent's calculator and batch read-only helpers accept native JSON arguments instead of failing on the first call ([#5800](https://github.com/raullenchai/Rapid-MLX/pull/5800)).

## Image: MiniMax-H3-Image and FLUX 3 Klein

`minimax-h3-image` (4-bit) and `minimax-h3-image-8bit` add text-to-image and edits that combine up to 16 reference images ([#5832](https://github.com/raullenchai/Rapid-MLX/pull/5832)). On an M3 Ultra with 256 GB (warm cache, seed 42), the measurements were:

| Quant | Load | Text-to-image, 1024² | Edit, 1 reference | Peak memory |
|---|---:|---:|---:|---:|
| 4-bit | 18–20 s | 77.1 s | 114.2 s | 47.0 GB |
| 8-bit | 20.3 s | 76.0 s | 114.2 s | 75.7 GB |

The MiniMax-H3-Image Community License excludes use in the European Union, United Kingdom, Republic of Korea and United States. It also requires separate authorization above US$1M annual revenue or for hosted third-party services. Responses carry the required attribution, and weights download from the upstream Hub only.

FLUX 3 Klein and Klein Base aliases are added, with up to ten edit references through the API and Desktop ([#5790](https://github.com/raullenchai/Rapid-MLX/pull/5790)). Qwen-Image checkpoints now advertise only the number of references they can actually use. A multi-reference edit beyond that limit returns a clear 400 instead of a 500 ([#5839](https://github.com/raullenchai/Rapid-MLX/pull/5839)).

Image generation and edits can apply your own LoRAs: drop `.safetensors` files into `~/.rapid-mlx/loras` and pick them by name ([#5792](https://github.com/raullenchai/Rapid-MLX/pull/5792)). The image runtime moves to mflux 0.23 with no generation behavior change ([#5787](https://github.com/raullenchai/Rapid-MLX/pull/5787)).

## Serve a LoRA Adapter Directly

`rapid-mlx serve <model> --adapter <dir>` applies an `mlx_lm.lora` adapter at startup, with no fuse or re-quantize step. The adapter's base model is checked whether you name the model by catalog alias, Hugging Face repo id or local cache path; adapters for a different base are rejected ([#5808](https://github.com/raullenchai/Rapid-MLX/pull/5808), [#5842](https://github.com/raullenchai/Rapid-MLX/pull/5842)).

`/v1/completions` now returns prompt-token logprobs for `echo` with `logprobs`. Scoring and loglikelihood evaluation clients use this combination ([#5809](https://github.com/raullenchai/Rapid-MLX/pull/5809)).

## Faster First Token on Long Cached Prompts

A single request that hits a long prefix cache no longer pays for extra KV copies. Each chat prompt is also tokenized once per request instead of several times ([#5831](https://github.com/raullenchai/Rapid-MLX/pull/5831), [#5803](https://github.com/raullenchai/Rapid-MLX/pull/5803), [#5810](https://github.com/raullenchai/Rapid-MLX/pull/5810), [#5829](https://github.com/raullenchai/Rapid-MLX/pull/5829)). The table shows warm-median TTFT on a 32k-token cache hit, measured on the server on an M5 Max over two alternating rounds ([#5831](https://github.com/raullenchai/Rapid-MLX/pull/5831)):

| Model | Before | After | Change |
|---|---:|---:|---:|
| Qwen3-1.7B 4-bit | 385 / 393 ms | 278 / 289 ms | −27% |
| Llama 3.2 1B Instruct 4-bit | 143 / 147 ms | 128 / 125 ms | −13% |
| Qwen3.6 35B-A3B 4-bit, speculation off | 581 / 596 ms | 582 / 578 ms | unchanged |

Decode speed and outputs are unchanged.

## Fixes

- Qwen3-Reranker (`mlx-community/Qwen3-Reranker-0.6B-4bit`) on `/v1/rerank` no longer returns 500 on every request. The prompt is built in the model's trained format, regardless of the checkpoint's chat template ([#5843](https://github.com/raullenchai/Rapid-MLX/pull/5843)).
- `/v1/embeddings` and `/v1/rerank` return 400 instead of 500 for input containing a lone UTF-16 surrogate, such as text extracted from some PDFs ([#5801](https://github.com/raullenchai/Rapid-MLX/pull/5801)).
- Desktop: conversation history is reachable from the compact sidebar rail in narrow windows ([#5799](https://github.com/raullenchai/Rapid-MLX/pull/5799)). Onboarding keeps the model name visible when a recommended row has long size details ([#5793](https://github.com/raullenchai/Rapid-MLX/pull/5793)).
- The project `LICENSE` is now the verbatim Apache-2.0 text, so license detection tools recognize it ([#5783](https://github.com/raullenchai/Rapid-MLX/pull/5783)).
