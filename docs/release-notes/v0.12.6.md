This release ends a version split that had started to reach users: from 0.12.6
onward the engine and the Rapid-MLX Desktop app carry **one** version number,
enforced in CI.

## Highlights

**The engine and the desktop app are one version again.** The two were
maintained by hand in different files — `pyproject.toml` for the engine,
`apps/rapid-mac/Resources/Info.plist` for the app — with nothing comparing
them, so they drifted apart. By 2026-08-07 the engine was 0.12.5 while the app
was 0.12.6, and both were correctly described as "the latest release": GitHub
showed 0.12.6, rapidmlx.com's install command showed 0.12.5, and neither was
wrong. Asked "which version are you running?", a user had no single answer to
give, and the download page read as stale when it was not.

This release moves the engine to 0.12.6 to meet the app, and adds a CI check
that fails any PR where the two disagree. It moves upward rather than aligning
down because a `rapid-mac-vX.Y.Z` tag already exists for every version the app
has shipped, and the in-app updater orders these values. The new check enforces
that the two files *agree*; that the number *increases* is already enforced by
`version-check.yml`. Together with the existing tag check in
`release-local.sh`, the chain is now closed end to end:
`git tag` = `Info.plist` = `pyproject.toml`.
([#1627](https://github.com/raullenchai/Rapid-MLX/pull/1627))

**Video-generation models are no longer offered as chat models.** Eight models
that cannot hold a conversation at all sat in the model picker and in Model
Management looking like ordinary chat models, with nothing to distinguish
them. Selecting one led to a start failure whose advice — "Try again" — would
have failed every time, and a user could reach that after downloading up to
64 GB. ([#1607](https://github.com/raullenchai/Rapid-MLX/pull/1607))

## Also in this release

- Qwen wrapper-quote stripping is now pinned in both directions by tests, so
  the 0.12.5 streaming fix cannot regress into over-stripping a value that
  legitimately begins and ends with a quote.
  ([#1601](https://github.com/raullenchai/Rapid-MLX/pull/1601))
- Desktop app 0.12.6 shipped separately on 2026-08-07 and is unchanged by this
  release; see `apps/rapid-mac/CHANGELOG.md` for its own notes.

## For contributors

`scripts/check_version_sync.py` runs on every PR from the Linux lint job
(stdlib only — no MLX, no macOS required) and is pinned by
`tests/test_version_sync.py`. If you are bumping the version, change **both**
`pyproject.toml` and `apps/rapid-mac/Resources/Info.plist` in the same PR; the
check prints both values and the file each came from when they disagree.
