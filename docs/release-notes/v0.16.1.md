Rapid-MLX 0.16.1 is a reliability and safety update for local serving, multimodal requests, installation, and coding-agent setup.

## Highlights

- **Safer local serving**: browser-origin and Host validation now reject drive-by access and DNS rebinding by default, while service qualification uses the trusted destination correctly. ([#4512](https://github.com/raullenchai/Rapid-MLX/pull/4512), [#4521](https://github.com/raullenchai/Rapid-MLX/pull/4521))
- **More reliable vision requests**: Anthropic image input is preserved, Gemma 4 12B image reading is restored, and qualified dense hybrid vision/text requests can batch without crossing capability boundaries. ([#4490](https://github.com/raullenchai/Rapid-MLX/pull/4490), [#4489](https://github.com/raullenchai/Rapid-MLX/pull/4489), [#4454](https://github.com/raullenchai/Rapid-MLX/pull/4454))
- **Actionable model lifecycle failures**: impossible model loads are rejected before healthy residents are evicted, low-memory switches are identified as retryable, and startup or residency failures now explain the recovery action. ([#4473](https://github.com/raullenchai/Rapid-MLX/pull/4473), [#4427](https://github.com/raullenchai/Rapid-MLX/pull/4427), [#4496](https://github.com/raullenchai/Rapid-MLX/pull/4496), [#4510](https://github.com/raullenchai/Rapid-MLX/pull/4510))
- **Installer and agent setup fixes**: streamed `curl | bash` installation no longer loses input to child package managers, and generated profiles better match current client configuration and server-root URL behavior. ([#4537](https://github.com/raullenchai/Rapid-MLX/pull/4537), [#4446](https://github.com/raullenchai/Rapid-MLX/pull/4446), [#4540](https://github.com/raullenchai/Rapid-MLX/pull/4540), [#4541](https://github.com/raullenchai/Rapid-MLX/pull/4541))
- **Serving and cache correctness**: dedicated embedding-only serving is available, recurrent hybrid KV quantization is selective, shared prompt state is charged once, and MCP cold startup and teardown are more robust. ([#4457](https://github.com/raullenchai/Rapid-MLX/pull/4457), [#4408](https://github.com/raullenchai/Rapid-MLX/pull/4408), [#4383](https://github.com/raullenchai/Rapid-MLX/pull/4383), [#4464](https://github.com/raullenchai/Rapid-MLX/pull/4464), [#4475](https://github.com/raullenchai/Rapid-MLX/pull/4475))
