Rapid-MLX 0.16.8 adds Flint support, lets concurrent short MTP chats decode together, and shows Desktop model loading inside the chat composer. DeepSeek V4.1 speculative verification has less overhead, and running servers discover updates without a restart.

## Highlights

- **Flint support**: serve the official INT4 checkpoint with `rapid-mlx serve flint-40b-a2.5b-4bit`. Measured on M5 Max 36 GB with mlx 0.32.4, greedy decoding and 256 output tokens: ~1K context reached 131 tok/s decode, 0.35–0.38 s time to first token (TTFT), and about 24 GB peak memory; ~8K context reached 118.5 tok/s and 2.2 s TTFT. Four concurrent ~1K requests reached 193 tok/s aggregate. A repeated prefix-cache request reduced TTFT from 0.46 to 0.15 s. These are workload-specific measurements; 48 GB or more unified memory is recommended. ([#5079](https://github.com/raullenchai/Rapid-MLX/pull/5079))
- **Concurrent short MTP chats no longer wait for one request to finish**: on M3 Ultra with `qwen3.8-27b-4bit`, four concurrent short chats increased aggregate throughput from 37.6 to 73.8 tok/s. Per-request TTFT changed from 0.6/4.0/7.3/10.8 s to about 1.4 s each. Single-stream performance is unchanged, and memory admission limits still apply. ([#5085](https://github.com/raullenchai/Rapid-MLX/pull/5085))

## Flint

- **Tool calls, reasoning and memory requirements**: Flint is a 40B-total, ~2.5B-active mixture-of-experts model, with tool-call and reasoning parsing configured automatically for the alias and recognized local checkpoints. KV cache stays bf16; `--kv-cache-dtype int8` is refused because quantized attention does not support its learned attention sinks. Speculative decoding and MTP are not enabled. It runs on 36 GB, but concurrent ~8K prefills are admitted one at a time on that memory size. ([#5079](https://github.com/raullenchai/Rapid-MLX/pull/5079))
- **Validated checkpoint revision enforced**: catalog aliases can now pin an optional immutable revision, and Flint is pinned to its validated checkpoint. Downloads, config and tokenizer reads, cache checks, and loading use that revision; an unavailable pin fails instead of silently selecting another revision. Explicit local paths remain local, and unpinned aliases retain their existing behavior. ([#5086](https://github.com/raullenchai/Rapid-MLX/pull/5086))

## DeepSeek V4.1

- **Less speculative verification overhead**: verification chunks of 2–8 tokens now use fused attention. On M3 Ultra 256 GB, measured target verification took about 6 ms less at a short prompt; most measured sizes saved 6–8 ms at ~7K context, while the five-row result there was within noise. These are verification timings, not end-to-end decode gains; single-row decode keeps its existing path. ([#5043](https://github.com/raullenchai/Rapid-MLX/pull/5043))

## Desktop

- **Model loading appears in the composer**: Desktop shows model loading inside the chat composer, keeping startup status where you write your message. ([#5056](https://github.com/raullenchai/Rapid-MLX/pull/5056))

## CLI and server

- **Updates appear while the server stays running**: text and audio servers re-check for releases every 24 hours and print a notice once per newly seen newer version. `GET /health` exposes `latest_version` and `update_available`; existing version-check opt-outs remain respected. ([#5061](https://github.com/raullenchai/Rapid-MLX/pull/5061))
- **Less first-request overhead for a private coding-agent profile**: the optimized private launch enables only shell commands, file reading, writing and editing, and file and text search, reducing the tool schemas sent with the initial request. Additional built-in tools remain available through manual setup. ([#5084](https://github.com/raullenchai/Rapid-MLX/pull/5084))

## Compute sharing

- **Request metrics and clearer runtime repair**: servers using the optional serial compute-sharing runtime now expose per-model request metrics at `/metrics`, recording streaming and non-streaming successes, failures and cancellations. Missing-runtime guidance gives a copyable install command for the Python interpreter running Rapid-MLX, with compatible dependency versions. ([#5002](https://github.com/raullenchai/Rapid-MLX/pull/5002))
- `models --cached` now shows catalog aliases for cached audio models, including Whisper, Kokoro, and Qwen3-TTS, while preserving exact repository, revision, and subfolder matching. (#5192)
