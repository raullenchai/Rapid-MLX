# Rapid-MLX 0.15.0

Rapid-MLX 0.15.0 adds privacy-safe product telemetry with clear local controls,
expands local image generation and editing with Qwen-Image 2.1, and brings a
new high-end local model to Server and Desktop. It also reduces idle Desktop
CPU use and makes common failures easier to understand and recover from.

## Private-by-construction telemetry with visible controls

Official 0.15.0 builds use one versioned telemetry pipeline for coarse product
signals such as model use, endpoint use, successful activity buckets, setup
events, and explicitly enumerated capability rejections. Events pass a closed
schema, use bounded local queues and counters, and are transmitted only from
an official release build after the applicable disclosure has been delivered.
Raw prompts, responses, file paths, request bodies, API keys, and arbitrary
model identifiers are not telemetry properties.

The first Desktop launch shows a one-time notice rather than an interrupting
consent dialog. Users can turn telemetry off at any time in Settings or with
`rapid-mlx telemetry off`; `status` explains the current decision and upload
gate, `preview` prints an example event without sending it, and `reset-id`
rotates the local installation identity. The former v1 collector and its
per-request wire are removed, so eligible installs do not double-report.

## Qwen-Image 2.1 generation and editing

Qwen-Image 2.1 now has a dedicated Server and Rapid Mac path instead of being
misrouted through the incompatible 1.x runtime. The integration uses the
family's Qwen3-VL encoder, supports text-to-image generation and one-image
img2img editing, and exposes the model in the Desktop Images workspace.

The qualified defaults use Q8 loading, 40 steps, guidance 1.0, tiled VAE, and
text-encoder eviction. Unsupported instruction-edit and incompatible
quantized packs are rejected before expensive model loading.

## Xiaomi MiMo-V2.6 Flash

The experimental `mimo-v2.6-flash-4bit` alias brings Xiaomi's 309B-total / 15B-
active MoE model to Server and the Desktop picker for Mac Studio-class systems
with at least 192 GB unified memory. Tool calling and JSON output use verified
parsers; the integration is text-only and does not claim unsupported vision,
audio, MTP, or DFlash execution.

On a 256 GB M3 Ultra, the qualified model used 164.3 GB resident memory and
peaked at 174 GB at 30K context. Decode ranged from 59 to 49 tok/s across the
4K-to-30K context sweep, and an exact cached repeat of a 15K document fell from
34.2 seconds cold to 0.95 seconds.

## Faster Gemma 4 with an explicit assistant sidecar

Operators can explicitly pair qualified Gemma 4 targets with an assistant
sidecar. Ordinary Gemma 4 inference remains unchanged and speculative decoding
is not enabled automatically. In the qualified M4 Pro eight-prompt matrix,
fixed K=3 improved pooled decode from 57.88 to 67.12 tok/s (1.16x) at 64.64%
draft acceptance. The gain remained workload-dependent, so the path is opt-in.

## A calmer, clearer Desktop

- The idle status animation no longer keeps the app rendering forever after a
  model becomes ready. On the measured M2 Pro system, idle CPU fell from
  58–60% to 1.2–3.6% without an attached accessibility client.
- Launching a second copy hands off to the existing app instead of starting a
  second engine on the same port; relaunching with only Settings previously
  restored now brings back the main window and engine.
- Model output keeps straight quotes, so displayed and copied JSON remains
  valid instead of being silently typeset with smart punctuation.
- Tool-use cautions appear only when an advertised tool could have served the
  request.
- Context overflow, unavailable models, load failures, memory exhaustion, and
  model replacement retain stable engine error codes and show recovery guidance
  suited to the real failure instead of a generic Retry card.
- `rapid-mlx feedback` and Desktop's Help menu offer a direct route to the
  community without attaching telemetry or sending diagnostic data.

## Community Benchmark and runtime reliability

The README gives Community Benchmark submissions a prominent path, an M5
MacBook Air result joins the public corpus, and Desktop benchmark progress no
longer overlaps its mascot.

The multimodal runtime continues its staged move toward Rapid-owned cache,
prefix-cache, and input-preparation primitives. This release preserves legacy
namespace recognition while removing dependency on the deprecated generation
surface.

## Upgrade

```bash
pip install -U rapid-mlx
```

Homebrew follows the Python package through its normal autobump process.
Desktop users receive the signed and notarized update through the production
appcast.
