Rapid-MLX 0.16.10 makes model downloads more reliable on restricted networks, restores immediate dictation capture, and adds three models. It also improves cached conversations and speeds up LFM2 MoE generation.

## Highlights

- **China-friendly model downloads**: covered, pinned models can download from the mirror without first contacting Hugging Face. Downloads still verify the expected file contents. Mirror downloads also handle models stored in subfolders, and cancelled pulls show how to retry. ([#5293](https://github.com/raullenchai/Rapid-MLX/pull/5293), [#5248](https://github.com/raullenchai/Rapid-MLX/pull/5248), [#5283](https://github.com/raullenchai/Rapid-MLX/pull/5283))
- **Dictation starts immediately**: Desktop begins capturing audio when you start dictation, avoiding the delay that could lose the beginning of a sentence. ([#5275](https://github.com/raullenchai/Rapid-MLX/pull/5275))
- **Cached transcription works offline**: speech-to-text can load a complete cached, pinned model and cached Whisper processor assets when Hugging Face is blocked or unavailable. Missing assets still need a network connection. ([#5301](https://github.com/raullenchai/Rapid-MLX/pull/5301))
- **Three new models**: Nanbeige4.3-33B, Spark-X2.6-4B, and Sage-A1.5 are available as pinned MLX aliases. See the [qualification record](https://github.com/raullenchai/Rapid-MLX/blob/main/docs/engineering/performance/2026-10-25-trending-models.md) for serving coverage, memory needs, and limits. ([#5279](https://github.com/raullenchai/Rapid-MLX/pull/5279))
- **Faster LFM2 MoE generation**: single-request, single-token decoding uses fused routing and expert combination. Measured decode gains were 11–17% on the tested Apple Silicon systems, with output matching the greedy baseline and unchanged peak memory. Set `RAPID_MLX_MOE_DECODE_FUSION=0` to disable the optimization. ([#5298](https://github.com/raullenchai/Rapid-MLX/pull/5298))
- **Cleaner model output**: Flint keeps its native automatic tool prompts, and fixes reduce exposed reasoning and malformed tool markup in supported output paths. Streaming marker recognition and reasoning delimiter handling are also improved. ([#5264](https://github.com/raullenchai/Rapid-MLX/pull/5264), [#5250](https://github.com/raullenchai/Rapid-MLX/pull/5250), [#5255](https://github.com/raullenchai/Rapid-MLX/pull/5255), [#5266](https://github.com/raullenchai/Rapid-MLX/pull/5266), [#5276](https://github.com/raullenchai/Rapid-MLX/pull/5276))
- **Better conversation cache reuse**: generation prefers longer cached prefixes that can actually be restored, with a safe fallback when restoration fails. ([#5253](https://github.com/raullenchai/Rapid-MLX/pull/5253))
- Local launches correctly select the provider from private configuration. ([#5256](https://github.com/raullenchai/Rapid-MLX/pull/5256))

The broader output-filtering changes in #5258 and #5267 were reverted to preserve streaming and are deferred to 0.17.0. Additional speech-to-text hardening and the separately tracked pre-existing issues remain outside this release.
