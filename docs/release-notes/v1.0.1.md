Rapid-MLX 1.0.1 requires Python 3.12 or newer, refuses catalog models that cannot fit before downloading them, adds five speech models, lets Community Benchmark measure with the same speed settings as `serve`, and fixes stalls, re-downloads and Desktop papercuts found after 1.0.0.

## Breaking: Python 3.12 or newer required

Rapid-MLX now requires Python 3.12+. Python 3.10 reaches end of life in October 2026, the chat harness, image and video lanes already needed a newer interpreter, and current numerical dependencies require 3.12. The official installer and the Desktop app already use 3.12. ([#5379](https://github.com/raullenchai/Rapid-MLX/pull/5379))

pip on Python 3.10 or 3.11 keeps resolving to 1.0.0. Install Python 3.12 (or newer) and reinstall to get newer releases. Homebrew users are unaffected.

## Highlights

- **Memory check before download**: `rapid-mlx serve <catalog model>` checks whether the model fits in this Mac's GPU memory before downloading it, and suggests a smaller model instead of downloading in full and failing at startup. ([#5402](https://github.com/raullenchai/Rapid-MLX/pull/5402))
- **New speech models**: speech-to-text adds `granite-speech`, `firered-asr2` and `nemotron-asr`; text-to-speech adds `voxcpm2` and `moss-tts-nano`. The new speech-to-text models also appear in Desktop's Speech to Text settings. ([#5381](https://github.com/raullenchai/Rapid-MLX/pull/5381))
- **Community Benchmark measures what serve runs**: `rapid-mlx benchmark run` now uses serve's default speed settings and accepts serve's acceleration flags, measures dedicated runtimes such as MTP and DFlash, and records the configuration that actually ran; `--baseline` keeps the original all-off protocol. Image-model runs save a complete recipe, draft-only MTP aliases are refused with the base model to use, and a benchmark whose local server stops now explains why. DFlash and native MTP benchmark runs on a fresh model cache now use the same pinned drafter that `serve` loads instead of failing to resolve it. ([#5376](https://github.com/raullenchai/Rapid-MLX/pull/5376), [#5382](https://github.com/raullenchai/Rapid-MLX/pull/5382), [#5389](https://github.com/raullenchai/Rapid-MLX/pull/5389), [#5392](https://github.com/raullenchai/Rapid-MLX/pull/5392), [#5397](https://github.com/raullenchai/Rapid-MLX/pull/5397), [#5411](https://github.com/raullenchai/Rapid-MLX/pull/5411))

## Fixes

- Strict JSON-schema requests can no longer emit whitespace indefinitely and hold the worker for minutes, which had delayed coding-agent turns behind a short title request. ([#5373](https://github.com/raullenchai/Rapid-MLX/pull/5373))
- Qwen3.8-27B models with a built-in MTP head start from an external model folder without re-downloading their weights. ([#5396](https://github.com/raullenchai/Rapid-MLX/pull/5396))
- `rapid-mlx share --install-service` installs a background service that runs the same Rapid-MLX install that ran the command, instead of an older copy found on PATH. ([#5370](https://github.com/raullenchai/Rapid-MLX/pull/5370))
- jina-reranker v3.5 honors its sliding-window attention layers, so scores match the reference for inputs longer than 1024 tokens. ([#5393](https://github.com/raullenchai/Rapid-MLX/pull/5393))
- Speech-to-text checkpoints apply the explicit code-consent policy when the model loads, with no extra work during dictation. ([#5291](https://github.com/raullenchai/Rapid-MLX/pull/5291))
- Releasing a model during garbage collection no longer risks a model-registry deadlock. ([#5372](https://github.com/raullenchai/Rapid-MLX/pull/5372))

## Desktop

- **Speech to Text settings**: download other speech models in place; sizes use one format and match Model Management; full model names and steadier download progress. ([#5374](https://github.com/raullenchai/Rapid-MLX/pull/5374), [#5377](https://github.com/raullenchai/Rapid-MLX/pull/5377))
- **Settings**: the "Release model when idle" row is no longer clipped, and model search points to matches on other tabs. ([#5374](https://github.com/raullenchai/Rapid-MLX/pull/5374))
- **Share Compute Credits** is fully translated in Simplified Chinese. ([#5371](https://github.com/raullenchai/Rapid-MLX/pull/5371))
- The anonymous first-run funnel reports why a model download or first engine start failed, as one cause from a fixed list plus the download source. No error text, paths or model names are sent. ([#5404](https://github.com/raullenchai/Rapid-MLX/pull/5404))
