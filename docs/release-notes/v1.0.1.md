Rapid-MLX 1.0.1 requires Python 3.12 or newer, refuses catalog models that cannot fit before downloading them, adds five speech models, lets Community Benchmark measure with the same speed settings as `serve`, and fixes stalls, re-downloads and Desktop papercuts found after 1.0.0.

## Breaking: Python 3.12 or newer required

Rapid-MLX now requires Python 3.12+. Python 3.10 reaches end of life in October 2026, the chat harness, image and video lanes already needed a newer interpreter, and current numerical dependencies require 3.12. The official installer and the Desktop app already use 3.12. ([#5379](https://github.com/raullenchai/Rapid-MLX/pull/5379))

**If you run 1.0.0 on Python 3.10 or 3.11, `pip install -U rapid-mlx` and older `rapid-mlx upgrade` report success but leave you on 1.0.0.** Move to Python 3.12 with the command for how you installed it:

- Installer: rerun `curl -fsSL https://rapidmlx.com/install.sh | bash`. It rebuilds the installer environment on Python 3.12 and keeps your settings, models, services and installed extras.
- uv: `uv tool upgrade --python 3.12 rapid-mlx`
- pipx: `pipx reinstall --python python3.12 rapid-mlx` (install Python 3.12 first if needed)
- pip: create a new Python 3.12 virtual environment and install there.
- Homebrew and the Desktop app: nothing to do.

See [Upgrading from Python 3.10 or 3.11](https://github.com/raullenchai/Rapid-MLX/blob/main/docs/getting-started/installation.md#upgrading-from-python-310-or-311). ([#5420](https://github.com/raullenchai/Rapid-MLX/pull/5420))

## Highlights

- **Memory check before download**: `rapid-mlx serve <catalog model>` checks whether the model fits in this Mac's GPU memory before downloading it, and suggests a smaller model instead of downloading in full and failing at startup. ([#5402](https://github.com/raullenchai/Rapid-MLX/pull/5402))
- **New speech models**: speech-to-text adds `granite-speech`, `firered-asr2` and `nemotron-asr`; text-to-speech adds `voxcpm2` and `moss-tts-nano`. The new speech-to-text models also appear in Desktop's Speech to Text settings. ([#5381](https://github.com/raullenchai/Rapid-MLX/pull/5381))
- **Community Benchmark measures what serve runs**: `rapid-mlx benchmark run` now uses serve's default speed settings and accepts serve's acceleration flags, measures dedicated runtimes such as MTP and DFlash, and records the configuration that actually ran; `--baseline` keeps the original all-off protocol. Image-model runs save a complete recipe, draft-only MTP aliases are refused with the base model to use, and a benchmark whose local server stops now explains why. DFlash and native MTP benchmark runs on a fresh model cache now use the same pinned drafter that `serve` loads instead of failing to resolve it. ([#5376](https://github.com/raullenchai/Rapid-MLX/pull/5376), [#5382](https://github.com/raullenchai/Rapid-MLX/pull/5382), [#5389](https://github.com/raullenchai/Rapid-MLX/pull/5389), [#5392](https://github.com/raullenchai/Rapid-MLX/pull/5392), [#5397](https://github.com/raullenchai/Rapid-MLX/pull/5397), [#5411](https://github.com/raullenchai/Rapid-MLX/pull/5411))

## Fixes

### Install and upgrade

- `rapid-mlx doctor` keeps the extras you already have when it suggests a uv or pipx command, allows time for the first import after an install, and treats running a virtual environment's `rapid-mlx` directly as a warning with a hint. ([#5521](https://github.com/raullenchai/Rapid-MLX/pull/5521))
- `rapid-mlx upgrade` verifies the installed version in a fresh process before reporting success. If the latest release needs newer Python, it installs the newest compatible release and prints the migration command; Homebrew updates are offered only when available. ([#5421](https://github.com/raullenchai/Rapid-MLX/pull/5421), [#5491](https://github.com/raullenchai/Rapid-MLX/pull/5491))
- Installer rebuilds preserve optional extras, settings, models and services, reuse an existing standalone Python, and validate the replacement before switching. Extras cannot downgrade base dependencies, legacy extras are retained, and concurrent installs are prevented. ([#5424](https://github.com/raullenchai/Rapid-MLX/pull/5424), [#5442](https://github.com/raullenchai/Rapid-MLX/pull/5442), [#5462](https://github.com/raullenchai/Rapid-MLX/pull/5462), [#5502](https://github.com/raullenchai/Rapid-MLX/pull/5502))
- Upgrade commands recognize macOS pipx installs, retain `--user` where supported, handle externally managed Python, and upgrade the selected environment even when another environment uses the same Python. `doctor` recommends only upgrades the detected installer can perform. ([#5448](https://github.com/raullenchai/Rapid-MLX/pull/5448), [#5450](https://github.com/raullenchai/Rapid-MLX/pull/5450), [#5491](https://github.com/raullenchai/Rapid-MLX/pull/5491), [#5477](https://github.com/raullenchai/Rapid-MLX/pull/5477))
- Installer output uses readable install labels, accurate Python and web UI status, and restart instructions for background services, including custom service names. Non-terminal output has no colour codes, and installs and upgrades no longer warn about a nonexistent `tokenizers` extra. ([#5432](https://github.com/raullenchai/Rapid-MLX/pull/5432), [#5442](https://github.com/raullenchai/Rapid-MLX/pull/5442), [#5450](https://github.com/raullenchai/Rapid-MLX/pull/5450), [#5462](https://github.com/raullenchai/Rapid-MLX/pull/5462), [#5463](https://github.com/raullenchai/Rapid-MLX/pull/5463), [#5502](https://github.com/raullenchai/Rapid-MLX/pull/5502))
- `rapid-mlx share --install-service` installs a background service that uses the same Rapid-MLX install that ran the command. ([#5370](https://github.com/raullenchai/Rapid-MLX/pull/5370))

### Serve and CLI

- Catalog models use the same memory-fit estimate across `serve` and Community Benchmark. Models with SSD-offloaded weights are judged by resident memory, cached image models are recognized, and measured image-generation memory is included. ([#5423](https://github.com/raullenchai/Rapid-MLX/pull/5423), [#5460](https://github.com/raullenchai/Rapid-MLX/pull/5460), [#5504](https://github.com/raullenchai/Rapid-MLX/pull/5504))
- Automatic MTP works on the first download, after a catalog revision changes, and from local catalog-model folders. Embedded heads are read locally without downloading the weights again; missing or empty heads fall back to plain decoding. ([#5396](https://github.com/raullenchai/Rapid-MLX/pull/5396), [#5434](https://github.com/raullenchai/Rapid-MLX/pull/5434), [#5457](https://github.com/raullenchai/Rapid-MLX/pull/5457), [#5506](https://github.com/raullenchai/Rapid-MLX/pull/5506))
- `/health` responds in every serving mode, including DFlash; retrieval-only servers report their model and update status, speech servers report speech capabilities, and dedicated speculative servers expose `/readyz` and `/livez`. ([#5430](https://github.com/raullenchai/Rapid-MLX/pull/5430), [#5418](https://github.com/raullenchai/Rapid-MLX/pull/5418), [#5452](https://github.com/raullenchai/Rapid-MLX/pull/5452), [#5481](https://github.com/raullenchai/Rapid-MLX/pull/5481))
- Ready banners show working examples for the active model and route, including reranking, voice cloning and forced alignment. Speech-only servers no longer suggest coding agents, accepted speech model names are retained, and background-service readiness reads the full response. ([#5427](https://github.com/raullenchai/Rapid-MLX/pull/5427), [#5455](https://github.com/raullenchai/Rapid-MLX/pull/5455), [#5478](https://github.com/raullenchai/Rapid-MLX/pull/5478), [#5489](https://github.com/raullenchai/Rapid-MLX/pull/5489), [#5505](https://github.com/raullenchai/Rapid-MLX/pull/5505))
- Piped `serve`, `benchmark` and `pull` output shows readable 10% download milestones. Desktop progress messages stay in the app, first downloads omit HTTP INFO lines and token warnings, and image/video serving logs show only relevant messages. ([#5447](https://github.com/raullenchai/Rapid-MLX/pull/5447), [#5434](https://github.com/raullenchai/Rapid-MLX/pull/5434), [#5464](https://github.com/raullenchai/Rapid-MLX/pull/5464))
- Model lists label reranker v3.5 correctly, including local copies, align speech model rows and omit empty text tables for audio-only listings. Refused models print their alias before the reason, and DFlash/DDTree emits one combined warning. ([#5427](https://github.com/raullenchai/Rapid-MLX/pull/5427), [#5455](https://github.com/raullenchai/Rapid-MLX/pull/5455), [#5461](https://github.com/raullenchai/Rapid-MLX/pull/5461))
- Clean shutdowns no longer leave empty crash reports; report cleanup preserves files still being written. Crash logs and serve markers respect `RAPID_MLX_STATE_DIR`. ([#5426](https://github.com/raullenchai/Rapid-MLX/pull/5426), [#5469](https://github.com/raullenchai/Rapid-MLX/pull/5469), [#5453](https://github.com/raullenchai/Rapid-MLX/pull/5453))
- Model release no longer risks a registry deadlock during garbage collection, and models remain loaded while agent or computer-use runs are pending. ([#5372](https://github.com/raullenchai/Rapid-MLX/pull/5372), [#5492](https://github.com/raullenchai/Rapid-MLX/pull/5492))
- DFlash without a drafter is refused before loading, and DDTree startup failures show the actual runtime error. ([#5460](https://github.com/raullenchai/Rapid-MLX/pull/5460))
- When a model doesn't fit, `serve` suggests one of the same kind that fits: an image or editing model for an image model, a text-diffusion model for a text-diffusion model. An explicitly requested MTP sidecar that can't be downloaded falls back to plain decoding with a single message instead of failing startup. Download, disk-space and recipe sizes in the CLI use decimal GB, matching the catalog and Desktop. `rapid-mlx doctor` reports installed chat and audio extras correctly and only suggests commands your installer can run. ([#5513](https://github.com/raullenchai/Rapid-MLX/pull/5513), [#5510](https://github.com/raullenchai/Rapid-MLX/pull/5510), [#5516](https://github.com/raullenchai/Rapid-MLX/pull/5516), [#5508](https://github.com/raullenchai/Rapid-MLX/pull/5508))
- A model refused for memory now suggests one already downloaded or one that fits on disk before a larger download. `rapid-mlx ls` reports real sizes for files in the shared download store and marks speech runtime files as `(runtime-files)` instead of incomplete. Ctrl-C or SIGTERM cancels a model download within seconds; completed files stay cached, so running the same pull again continues from there. ([#5519](https://github.com/raullenchai/Rapid-MLX/pull/5519), [#5524](https://github.com/raullenchai/Rapid-MLX/pull/5524), [#5520](https://github.com/raullenchai/Rapid-MLX/pull/5520), [#5523](https://github.com/raullenchai/Rapid-MLX/pull/5523))

### API

- Strict JSON-schema requests can no longer emit whitespace indefinitely and hold the worker for minutes, delaying other requests. ([#5373](https://github.com/raullenchai/Rapid-MLX/pull/5373))
- Tool-only assistant turns return `content: null`, including DFlash streamed tool-call deltas. Prose before a streamed tool call appears once, and DeepSeek V4-Flash correctly reads flattened tool-call history. ([#5419](https://github.com/raullenchai/Rapid-MLX/pull/5419), [#5472](https://github.com/raullenchai/Rapid-MLX/pull/5472), [#5476](https://github.com/raullenchai/Rapid-MLX/pull/5476), [#5475](https://github.com/raullenchai/Rapid-MLX/pull/5475))
- `/v1/messages` accepts tool names up to 128 characters and identifies invalid names as `tools[i].name`; TensorFold accepts explicit `tool_choice: "auto"`. ([#5417](https://github.com/raullenchai/Rapid-MLX/pull/5417), [#5455](https://github.com/raullenchai/Rapid-MLX/pull/5455), [#5474](https://github.com/raullenchai/Rapid-MLX/pull/5474))
- Long prompts with several images are processed in chunks, allowing other requests to progress. GPU exhaustion returns a clear memory error that clients do not retry blindly, and a failed processing step affects only its own requests. ([#5436](https://github.com/raullenchai/Rapid-MLX/pull/5436), [#5484](https://github.com/raullenchai/Rapid-MLX/pull/5484))
- Repeated image requests reuse the cached image prefix, including short follow-up questions. Resized images use the correct cached vision features. ([#5439](https://github.com/raullenchai/Rapid-MLX/pull/5439), [#5454](https://github.com/raullenchai/Rapid-MLX/pull/5454), [#5485](https://github.com/raullenchai/Rapid-MLX/pull/5485))
- jina-reranker v3.5 applies sliding-window attention correctly on long inputs and uses the correct length limits; long-document reranking uses substantially less peak memory. ([#5393](https://github.com/raullenchai/Rapid-MLX/pull/5393), [#5415](https://github.com/raullenchai/Rapid-MLX/pull/5415), [#5480](https://github.com/raullenchai/Rapid-MLX/pull/5480))
- `/v1/messages/count_tokens` on vision-capable models counts the same system prompt, tools and messages the model receives. ([#5512](https://github.com/raullenchai/Rapid-MLX/pull/5512))

### Speech

- Local speech model folders serve with the same defaults, voice choices and cloning capabilities as their catalog counterparts, regardless of folder name. Local MOSS models can fetch their companion codec. ([#5435](https://github.com/raullenchai/Rapid-MLX/pull/5435), [#5497](https://github.com/raullenchai/Rapid-MLX/pull/5497))
- Transcription `verbose_json` reports actual audio duration and segment end times; untimed segments span the recording, sentence timing is retained for subtitles, and forced alignment reports the full input duration. AIFF uploads work, and unreadable uploads list supported formats. ([#5425](https://github.com/raullenchai/Rapid-MLX/pull/5425), [#5452](https://github.com/raullenchai/Rapid-MLX/pull/5452), [#5482](https://github.com/raullenchai/Rapid-MLX/pull/5482))
- Common voice names such as `alloy` work across text-to-speech models, and `whisper-1` selects the served speech-to-text model. ([#5459](https://github.com/raullenchai/Rapid-MLX/pull/5459))
- Speech backends honor playback speed and language hints, Granite reports the requested language accurately, and long FireRedASR2 recordings are transcribed in smaller windows instead of failing. ([#5482](https://github.com/raullenchai/Rapid-MLX/pull/5482))
- Whisper processor assets download at the model’s pinned revision, so the first transcription can work offline; VoxCPM2 loads without a misleading warning. ([#5486](https://github.com/raullenchai/Rapid-MLX/pull/5486), [#5461](https://github.com/raullenchai/Rapid-MLX/pull/5461))
- A pulled Whisper model transcribes offline on its first request. Speech-only `serve` prepares the text-to-speech runtime while online, so the README example works; the README lists the current speech aliases and its examples fail visibly on errors. ([#5507](https://github.com/raullenchai/Rapid-MLX/pull/5507), [#5511](https://github.com/raullenchai/Rapid-MLX/pull/5511), [#5509](https://github.com/raullenchai/Rapid-MLX/pull/5509))

### Image and video

- Image generation keeps GPU memory bounded, including after another engine loads. flux2-klein, z-image and SDXL use substantially less peak memory; FLUX.1 schnell has a corrected memory estimate and a 32 GB minimum. ([#5437](https://github.com/raullenchai/Rapid-MLX/pull/5437), [#5479](https://github.com/raullenchai/Rapid-MLX/pull/5479))
- Completed video jobs restart the idle-release timer, and MiniMax-H3 encodes output with the detected video encoder. ([#5473](https://github.com/raullenchai/Rapid-MLX/pull/5473), [#5483](https://github.com/raullenchai/Rapid-MLX/pull/5483))

### Community Benchmark

- Runs record the snapshot, quantization, acceleration settings, runtime context and embedded MTP head that actually loaded. Pinned targets and drafters work with partial caches, and valid PFlash settings save correctly. ([#5422](https://github.com/raullenchai/Rapid-MLX/pull/5422), [#5446](https://github.com/raullenchai/Rapid-MLX/pull/5446), [#5468](https://github.com/raullenchai/Rapid-MLX/pull/5468), [#5488](https://github.com/raullenchai/Rapid-MLX/pull/5488))
- Runs reject models that do not fit before downloading, refuse image models that cannot run the workload, and validate unsupported acceleration settings before loading. ([#5430](https://github.com/raullenchai/Rapid-MLX/pull/5430), [#5449](https://github.com/raullenchai/Rapid-MLX/pull/5449), [#5460](https://github.com/raullenchai/Rapid-MLX/pull/5460), [#5488](https://github.com/raullenchai/Rapid-MLX/pull/5488))
- Ctrl-C and SIGTERM stop runs promptly, including while text models load, and benchmark server processes are cleaned up. Failures distinguish server crashes from out-of-memory exits and explain video download problems. ([#5397](https://github.com/raullenchai/Rapid-MLX/pull/5397), [#5429](https://github.com/raullenchai/Rapid-MLX/pull/5429), [#5470](https://github.com/raullenchai/Rapid-MLX/pull/5470), [#5467](https://github.com/raullenchai/Rapid-MLX/pull/5467))
- Engine INFO logs are hidden by default; `--log-level` also controls image and video servers. Help lists only the command’s own flags, messages use plain language, and catalog/plan sizes share one GB format with downloaded models marked. ([#5414](https://github.com/raullenchai/Rapid-MLX/pull/5414), [#5441](https://github.com/raullenchai/Rapid-MLX/pull/5441), [#5458](https://github.com/raullenchai/Rapid-MLX/pull/5458), [#5470](https://github.com/raullenchai/Rapid-MLX/pull/5470), [#5451](https://github.com/raullenchai/Rapid-MLX/pull/5451))

### Security

- Speech checkpoints enforce repository-code consent when loading; refused speech requests return HTTP 403 with the opt-in instruction. Consent also covers executable code in nested tokenizer or processor folders and loaders that require repository code. ([#5291](https://github.com/raullenchai/Rapid-MLX/pull/5291), [#5456](https://github.com/raullenchai/Rapid-MLX/pull/5456), [#5498](https://github.com/raullenchai/Rapid-MLX/pull/5498))
- DeepSeek V4 tool calls are recognized only inside tool-call envelopes, and every serving lane removes special tokens from user content before applying the chat template. ([#5487](https://github.com/raullenchai/Rapid-MLX/pull/5487))
