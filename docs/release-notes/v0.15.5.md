Rapid-MLX 0.15.5 makes experimental Computer Use less disruptive, speeds up
qualified speculative decoding, and improves model import and server recovery.

## Highlights

**Computer Use can act without taking over your Mac.** Supported clicks, text
entry, and keystrokes are routed to the exact app and window approved for the
task, while the app you are actively using stays in front. Window identity is
checked immediately before input, focus restoration is skipped if you switch
apps during an action, and ambiguous or unsupported background targets fail
closed. This remains an experimental feature and still requires macOS Screen
Recording and Accessibility permission. ([#4052](https://github.com/raullenchai/Rapid-MLX/pull/4052))

**Less host overhead during accepted MTP drafts.** Qualified continuous
self-MTP decoding now performs one host synchronization per accepted draft
cycle rather than one per proposed token. The output contract and existing
profile eligibility checks are unchanged; the gain depends on draft acceptance
and workload. ([#4071](https://github.com/raullenchai/Rapid-MLX/pull/4071))

**Bring-your-own-model setup fails earlier and recovers better.** Rapid checks
uncataloged models before downloading them, suggests a runnable alternative
when a model does not fit the current machine or runtime, and provides an
explicit, cancel-safe path to import and quantize compatible MLX models. Support
requests remain opt-in. ([#4002](https://github.com/raullenchai/Rapid-MLX/pull/4002), [#4004](https://github.com/raullenchai/Rapid-MLX/pull/4004), [#4008](https://github.com/raullenchai/Rapid-MLX/pull/4008), [#4012](https://github.com/raullenchai/Rapid-MLX/pull/4012))

**Clearer server startup and compatibility behavior.** First-start failures
now identify the failing stage and provide specific recovery guidance.
Text-capable vision checkpoints can use the text lane when optional vision
dependencies are absent, a universal context-length override is available,
and advanced sampling inputs are validated explicitly instead of being silently
changed. ([#4001](https://github.com/raullenchai/Rapid-MLX/pull/4001), [#4014](https://github.com/raullenchai/Rapid-MLX/pull/4014), [#4035](https://github.com/raullenchai/Rapid-MLX/pull/4035), [#3968](https://github.com/raullenchai/Rapid-MLX/pull/3968))

**More reliable local coding agents.** Prefix-cache handling, numeric JSON
arguments, undeclared tool markup, headless profiles, and caller attribution
were tightened across the supported agent integrations. ([#4056](https://github.com/raullenchai/Rapid-MLX/pull/4056), [#4058](https://github.com/raullenchai/Rapid-MLX/pull/4058))

## Desktop polish and reliability

- Model unload is now a labelled action beside the active model, with guarded
  behavior while work is in progress.
- Restart-loop telemetry preserves paired attempt/outcome events while sampling
  timestamps after lock contention.
- Benchmark sharing now points to the reproducible benchmark workflow and
  refuses empty or invalid runs.
