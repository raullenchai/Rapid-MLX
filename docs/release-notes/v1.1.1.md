Rapid-MLX 1.1.1 adds native support for Hy4 flash, including a 4-bit build that runs on a 128 GB Mac. Inkling 2 Mini decodes faster, drops to its lowest reasoning effort when thinking is turned off, and its official checkpoint now serves directly. Desktop keeps the dictation hotkey working across an update, and image and video models start again when idle model release is turned on.

**Download:** [Rapid-MLX Desktop for macOS](https://github.com/raullenchai/Rapid-MLX/releases/download/rapid-mac-v1.1.1/rapid-mlx-desktop.dmg) | CLI: `rapid-mlx upgrade`

## Hy4 flash

- `rapid-mlx serve rapid-mlx/Hy4-flash-MLX-4bit` serves Hy4 flash natively, text only. The 4-bit GPTQ build is 139 GB on disk and uses about 102 GB of memory for a single request, because Rapid-MLX reads the model's Engram lookup tables from SSD as they are needed. It targets Macs with 128 GB of unified memory or more ([#5880](https://github.com/raullenchai/Rapid-MLX/pull/5880)).
- The model loads by repository name straight from the Hugging Face cache, with no separate download step ([#5922](https://github.com/raullenchai/Rapid-MLX/pull/5922)).
- Evaluation results and the list of changes from the original weights are on the [model page](https://huggingface.co/rapid-mlx/Hy4-flash-MLX-4bit). The model is distributed under the Tencent Hy License.

## Inkling 2 Mini

- Single-request decode is faster. Three changes fuse small per-token operations into single Metal kernels and compile the stateless decode blocks once per shape; each is worth a few percent of decode speed, with no change to prefill or memory ([#5918](https://github.com/raullenchai/Rapid-MLX/pull/5918), [#5919](https://github.com/raullenchai/Rapid-MLX/pull/5919), [#5920](https://github.com/raullenchai/Rapid-MLX/pull/5920)).
- Turning thinking off now reaches the model. A request with `enable_thinking: false`, or one where Rapid-MLX turns thinking off automatically, is sent with reasoning effort `none`, the model's lowest level. At that level the model may still write a short thought before answering, but it no longer reasons at its default effort ([#5917](https://github.com/raullenchai/Rapid-MLX/pull/5917)).
- The official Inkling 2 Mini checkpoint serves directly with `rapid-mlx serve`, on the text lane ([#5924](https://github.com/raullenchai/Rapid-MLX/pull/5924)).
- Inkling 2 Mini works again on MLX 0.32.1 and 0.32.2. On those versions every chat request failed with a 503 error; this affected installs that were upgraded in place and kept an older MLX ([#5931](https://github.com/raullenchai/Rapid-MLX/pull/5931)).
- Measured serving performance on an M5 Max is recorded in [docs/benchmarks](https://github.com/raullenchai/Rapid-MLX/blob/main/docs/benchmarks/inkling-2-mini-m5-max.md) ([#5926](https://github.com/raullenchai/Rapid-MLX/pull/5926)).

## Desktop

- The dictation hotkey stays enabled after the app relaunches for an update. Before, an update could leave dictation switched off until it was turned on again in Settings ([#5921](https://github.com/raullenchai/Rapid-MLX/pull/5921)).
- Image and video models start again when "release the model when idle" is turned on. Before, they failed with "This model couldn't load". With the setting on, these models now stay loaded until they are stopped or switched; releasing them when idle is tracked in [#5935](https://github.com/raullenchai/Rapid-MLX/issues/5935) ([#5934](https://github.com/raullenchai/Rapid-MLX/pull/5934)).

## Install

- Piping the installer to `sh` instead of `bash` now fails with one clear line that shows the right command, instead of a syntax error ([#5913](https://github.com/raullenchai/Rapid-MLX/pull/5913)).
- `flux3-klein` and `flux3-klein-base` download from the Hugging Face Hub, where their license must be accepted first ([#5912](https://github.com/raullenchai/Rapid-MLX/pull/5912)).
