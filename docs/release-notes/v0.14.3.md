# Rapid-MLX 0.14.3

Rapid-MLX 0.14.3 makes repeat multimodal conversations materially faster,
extends Personal Intelligence from answers into bounded local work, and gives
Community Benchmark a complete, trustworthy Desktop experience. It also fixes
the downloaded DMG install window on affected macOS releases and adds native
support for Bonsai 2 Hadamard model packs.

## Faster multimodal conversations

Two default-on, fail-closed optimizations remove work from the serialized
multimodal lane without changing outputs outside their qualified boundary.

| Qualified Qwen3.6 35B media workload | Before | After |
| --- | ---: | ---: |
| Second-turn media-prefix TTFT | baseline | **54.8% lower** |
| Second-turn elapsed time | baseline | **22.4% lower** |
| Singleton-lane generation throughput | baseline | **35.4% higher** |

The media-aware prefix cache retains the exact prior-turn media boundary, so a
follow-up question about the same image need not encode the image and prefill
the unchanged conversation again. Its one-time storage cost was 10–25 ms on
short eligible first turns and cost-neutral on long prompts. The singleton fast
path separately skips merging and repacking a cache whose shape is already
correct; the measured 21-case suite kept identical response hashes and peak
memory. Both paths retain explicit rollback settings.

Multimodal sampling also reaches parity with text generation: `seed`, `top_k`,
and `min_p` are no longer ignored by the media scheduler.

## Personal Intelligence can complete local work

Qualified local models in Desktop can now search and read local text, write a
reviewed file, move one file to recoverable Trash, and compile or run a bounded
development command. This supports requests such as finding a note in a folder,
saving a draft, or writing, compiling, and running a small program without
turning the feature into a general shell.

The safety boundary is explicit:

- Desktop shows the exact path, content, command, and arguments before access.
- Search/read may be approved once or for the current app session; writes,
  execution, and Trash always require a fresh one-time approval.
- Paths stay under the user's home directory, while hidden files, symlinks,
  credential stores, package descendants, and oversized or non-text inputs are
  rejected.
- Commands run without a shell in a time-, output-, filesystem-, network-, and
  process-bounded macOS sandbox. Compiler plugins and indirect argument files
  are unavailable.

Generated work defaults to `~/Rapid Workspace` when the request does not name a
destination. The rollout remains restricted to model/build pairs that passed
the Personal Intelligence qualification contract.

## A complete Community Benchmark experience

The Desktop Community Benchmark now exposes live stages, pass counts, ETA, and
the latest measurement while a run is active. Results provide clear routes to
run another model or repeat the same model, contributor identity survives an
app restart, and My Results and Community views distinguish exact totals from
bounded recent evidence instead of inventing zeroes or comparisons.

Publication is also release-shaped: the completed result keeps its immutable
model, protocol, execution, Mac, and contributor scope even if the visible
selection changes, and packaged builds carry provenance that is stamped and
verified before measurement can be published. Modified source builds remain
usable for local measurement but fail closed at publication.

DeepSeek V4.1 can now run the registered benchmark through its qualified serial
runtime. On a 256 GB M3 Ultra, the pinned 2-bit path measured approximately
31.09 tok/s for the short case and 29.42 tok/s for the long case; its DSpark
method, sidecar identity, K4 block size, and 8,192-token input limit are recorded
with the result.

## More local models

Bonsai 2 Hadamard MLX packs now use a Rapid-owned loader for their packed
Hadamard projections and inverse embeddings. The qualified integration covers
text, streaming, and image HTTP requests while preserving existing multimodal
serving behavior.

## Long-context and reliability fixes

- GLM-5.3 Flash native MTP now prefills in bounded 1,024-token chunks instead
  of materializing a roughly 32K prompt in one target forward. Two consecutive
  real 32K HTTP requests completed on a 256 GB M3 Ultra without Metal OOM. This
  does not claim the checkpoint's advertised 1M context is usable.
- Gracefully stopping `rapid-mlx serve` avoids the macOS 15 Python-finalization
  race that could hang or crash the process at shutdown.
- A cancelled DNS-pinned Desktop request cannot resume the same continuation
  twice.
- A sandboxed Personal Intelligence command now returns at its hard deadline
  even if macOS is slow to tear down a denied child process, instead of leaving
  the Desktop task and test runner waiting indefinitely.
- The Python distribution now uses the canonical `rapid_mlx` package name while
  preserving a compatibility shim for existing imports.
- Opening "See what's new" or the GitHub prompt no longer performs Desktop
  state changes from a non-main thread.

## DMG installation fix

The 0.14.0–0.14.2 DMG stored two Finder view records in a nested binary-plist
shape that could close the install window on current macOS and crash/relaunch
Finder on Sonoma. The layout is now generated deterministically with the flat
dictionary records Finder writes itself, and the release verifier rejects the
old encoding. The branded background and Applications drag target render again.

## Upgrade

```bash
pip install -U rapid-mlx
```

Homebrew follows the package release through its normal autobump process.
Desktop users receive the signed and notarized update through the production
appcast.
