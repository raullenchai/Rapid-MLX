# LFM3 native qualification

The `lfm3-1.7b-8bit` alias pins `LiquidAI/LFM3-1.7B-MLX-8bit` at
`ee7667f3cfccb2a41725f91820531823fcabc6b7` (LFM Open License v1.0).
The 4-bit checkpoint is not included. Its comparison with bf16 on the
same reference implementation yielded 867/1024 top-1 and mean KL 0.1310.

## Correctness

On M5 Max (36 GiB), macOS 27.0.1, Python 3.12.13, MLX 0.32.4 and
mlx-lm 0.31.3, compare 1024 teacher-forced natural-prose tokens against an
independent implementation using the same weights. Input text SHA-256:
`21da713e04f3661f78e208b37226b0c5651eb5148d2dcc97a601ca371b0742fb`.
The bf16 revision was `40ebe0aa6662c9d40389c2f5d565b6a2c6aebacd`.
The input exceeds the 256-token sliding window.

| Comparison | Top-1 agreement | Mean KL |
| --- | ---: | ---: |
| Native bf16 vs reference bf16 | 1024/1024 | 0 |
| Native 8-bit vs reference 8-bit | 1024/1024 | 0 |
| Reference 8-bit vs bf16 | 999/1024 | 0.0039754 |

For 270 tokens, native 8-bit full forward vs single-token decoding agrees
on 261/270 top-1, maximum absolute logit difference 2.375; the independent
reference also agrees on 261/270, maximum difference 2.37890625. The first
divergence occurs in the layer-zero quantized projection before cache or
attention. Different matrix shapes use different quantized arithmetic.
With identical 260+10 chunking, real prefix-cache store/fetch and cold
execution agree exactly (10/10 top-1, max difference 0).

The random float32 unit test exercises all three cache types over 300 tokens
with window 256. Full forward vs chunks of 1 and 37 gives maximum absolute
logit differences 3.10e-6 and 2.35e-6 respectively, with 300/300 top-1
agreement for each. Prefix-cache store/fetch vs cold execution is also
checked for max difference <= 1e-3 and identical top-1.

## Server qualification

On leased studio-max, a fresh Python 3.12 venv installed the branch without
the vision extra. The server ran with a temporary HOME and the shared default
Hugging Face cache, telemetry disabled, and `rapid-mlx serve lfm3-1.7b-8bit`
on loopback. English and Chinese prompts produced relevant answers; streaming
produced multiple content deltas; `get_weather` returned `{"city":"Paris"}`
with `finish_reason=tool_calls`. Thinking enabled returned reasoning and the
answer; a thinking-disabled English request returned only the answer. A
follow-up with thinking disabled nevertheless emitted explicit reasoning,
which the server separated from content; the template switch is a model
instruction, not a guarantee against model-generated thinking tags. A
two-turn request reported 147 cached tokens.

For the English prompt (19 prompt, 41 completion tokens), server TTFT was
167.4 ms and mean inter-token latency 5.35 ms (approximately 187 tokens/s).
The SSE request had 34.5 ms server TTFT and 5.33 ms mean inter-token latency.
These are single warm-server observations, not a throughput benchmark.
