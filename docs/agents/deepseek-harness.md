# DeepSeek Harness

Install Rapid-MLX on an Apple Silicon Mac and restart Terminal:

```bash
curl -fsSL https://rapidmlx.com/install.sh | bash
```

Run `rapid-mlx recipe` to choose a model that fits this Mac, then start it with `rapid-mlx serve <alias>`. In another terminal, run `rapid-mlx agents deepseek-harness` for this client’s connection instructions.
