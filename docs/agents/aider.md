# Aider

Install Rapid-MLX on an Apple Silicon Mac and restart Terminal:

```bash
curl -fsSL https://rapidmlx.com/install.sh | bash
```

Run `rapid-mlx launch list` to see the current integration for Aider. The [agent guides](https://rapidmlx.com/docs/agents/) cover local connection details. Run `rapid-mlx recipe` to choose a model that fits this Mac.
